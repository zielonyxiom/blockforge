# BlockForge (Modeler)

Picture → stud-style Roblox model. Overview and pipeline: README.md.

- House style for trees/plants: training/STYLE.md (read before building one). Saplings: training/SAPLINGS.md.
- Build flow: BlockForge MCP tools (server instructions list the order); Roblox Studio MCP for placing/inspecting in Studio; Blender MCP only for mesh work BlockForge cannot do.
- Free HF 3D-scan quota often runs out: build without a scan rather than retrying.
- Keep untracked scripts in scripts/; do not commit training/ dumps without asking.
- Building trees directly in Roblox Studio (concept trees, bundles): docs/STUDIO_TREE_GUIDE.md — read it fully first; helpers in studio/*.lua, rules in docs/TREE_DESIGN_RULES.md.
